# Issue tracker: Linear (other)

Issues and specs for this repo live in the **Personal Web** Linear project (`P-MUH-2`, team `MUH`) at https://linear.app/muhammad-taufiqurrahman/project/personal-web-6bce0292147b/overview. Use the Linear MCP tools for all operations — never `gh issue`. Create with `save_issue` (`team: "MUH"`, project `P-MUH-2`), read with `get_issue` + `list_comments`, list with `list_issues` scoped to the project, comment with `create_comment`, and update status via `save_issue` using the team's statuses (`Backlog`, `Todo`, `In Progress`, `In Review`, `Done`, `Canceled`, `Duplicate`). Use existing labels `Feature`/`Bug`/`Improvement` plus the triage labels in `docs/agents/triage-labels.md`; use Linear sub-issues for parent/child and `Blocked by` relations for blockers. When a skill says "publish to the issue tracker", create a Linear issue in `P-MUH-2`; when it says "fetch the relevant ticket", read it with `get_issue`.
